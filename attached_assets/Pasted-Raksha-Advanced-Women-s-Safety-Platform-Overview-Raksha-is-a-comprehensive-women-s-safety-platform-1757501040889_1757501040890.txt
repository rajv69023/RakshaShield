Raksha - Advanced Women's Safety Platform
Overview
Raksha is a comprehensive women's safety platform that provides real-time emergency response, biometric monitoring, and AI-powered safety assistance. The application combines modern web technologies with advanced safety features including SOS alerts, voice stress analysis, location-based safety recommendations, and a guardian network system. Built as a full-stack TypeScript application, it features a React frontend with Express backend, PostgreSQL database, and WebSocket real-time communication.

User Preferences
Preferred communication style: Simple, everyday language.

System Architecture
Frontend Architecture
React SPA: Built with Vite for fast development and optimized builds
UI Framework: Shadcn/ui components with Radix UI primitives for accessibility
Styling: Tailwind CSS with custom design tokens and responsive design
State Management: React Query for server state, React hooks for local state
Routing: Wouter for lightweight client-side routing
Real-time Communication: WebSocket integration for live emergency alerts
Backend Architecture
Express.js Server: RESTful API with middleware for logging and error handling
TypeScript: Full type safety across frontend and backend
Real-time Features: WebSocket server for emergency broadcasts and live updates
Service Layer: Modular services for emergency response, AI analysis, and geolocation
Storage Abstraction: Interface-based storage layer supporting multiple implementations
Database Design
PostgreSQL: Primary database with Drizzle ORM for type-safe queries
Schema Structure:
Users with emergency contacts and biometric settings
Emergency alerts with location and biometric data
Guardian network for community response
Evidence vault for secure data storage
AI interactions for chat history and sentiment analysis
Key Features
Emergency System: Multi-trigger SOS (manual, biometric, voice stress) with automatic contact alerting
Biometric Monitoring: Heart rate and stress level tracking with threshold-based alerts
AI Companion: OpenAI integration for voice stress analysis and safety recommendations
Location Services: Safety zone mapping and location-based risk assessment
Guardian Network: Community-based emergency response system
Evidence Vault: Secure storage for emergency-related media and data
Security & Safety
Real-time Alerts: WebSocket-based emergency broadcasting to contacts and guardians
Location Privacy: Configurable location sharing with emergency override
Data Protection: Secure evidence storage with tamper-proof blockchain concepts
Multi-channel Communication: SMS, calls, and in-app notifications for emergency contacts
